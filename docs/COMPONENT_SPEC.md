# 默认视觉与主题契约

来源：Ether `docs/KANESUMI_DESIGN.md`、裁定 K-79 / §112，以及 Kanesumi 主仓
`0ac3f16` 的 `colors.rs` / `accent.rs` / `typography.rs` / `button.rs`。
Lumia 原图仅用于对比度、层次和留白参考，胶囊、圆形不移植。

## 主题与文字

- `MetroTheme()` 零配置采用浅色 + 暮蓝，与主仓默认方案一致。
- `MetroColors()` 保持暗色构造语义，暗色中性层改为 Lumia 方案：背景黑、表面
  `#171717`、次级表面 `#333333`、正文白。显式构造参数继续优先。
- `MetroColors.light(accent)` / `dark(accent)` 提供完整方案；浅色中性色按主仓已落地值，
  不采用临时登记中尚未验收的 WinUI 候选值。
- 强调色基色默认 `#2D6FE0`；暗色主色取 HSV Light1（V×1.17，越界时
  S×(2−V′)），模型与主仓一致，不声称复刻闭源 Windows 色相调整。
- 强调填充上的前景比较黑白相对亮度对比度，选择较高者；普通控件填充独立于表面色。
- 现有颜色构造参数顺序保持，新增字段追加；未指定的控件填充从现有 surfaceVariant 派生，
  让 Ncrust 的显式调色板继续生效。
- 标题 Light、正文 Regular；补 header/subheader/subtitle/base 语义阶梯，已有参数顺序保持。
  不新增字体依赖，字体回退由 Android 完成。

## 按钮与列表

- 按钮默认 Standard：中性控件填充 + 正文；Accent 通过追加的 kind 参数显式选择。
  显式 containerColor/contentColor 仍覆盖 kind；自定义底色的默认前景按对比度解析。
- 保留既有 padding 参数，最小布局高度 48dp；文本默认单行省略，禁止短动作被同排控件挤成多行。
  clickable 提供 Button role、禁用状态和键盘入口；禁用只降低前景强度。
- 列表保留 0dp 左边距；主副文本默认单行省略，追加行数参数供需要多行的消费方选择。
- 歌词过去/未来颜色随主题前景派生，不再固定白/灰；动画读取阶段和既有时长不变。
  浅色实图中未来行 alpha 0.65 仅 2.88:1，默认改为 0.8，保留大字层级同时提高可读性。
- Switch 保留 52×28dp 直角几何与既有拖动参数；Off 中空、2dp 强轮廓，On 强调底，
  两态各自选择可读 thumb。提供 Switch role、状态与无障碍激活动作；不声称补齐键盘拖动。

## 响应式与展示

- ResponsiveContent 未指定宽度时：窄于 600dp 保持 360dp 上限；宽屏铺开并留 24dp。
  显式 maxWidthDp 在所有宽度仍作为上限。
- sample 提供概览、控件、版式、工具四个入口；深浅主题可运行时切换。
  工具页承载安全区和焦点诊断，默认页只展示内容。
- 宽屏使用侧栏；底部导航与 mini bar 只在存在时登记高度，系统导航安全区独立登记。
- sheet 在 Shell 之后绘制且接管返回；歌词与页面顶部避开状态栏，底部操作避开叠层。
  系统栏明暗跟随 sample 选定主题。
- 普通滚动页的视口保留状态栏安全区，AppBar 不再重复补偿，让滚动裁剪与焦点定位都避开系统栏；
  状态栏区域绘制主题表面色，图片详情继续用原有 scrim。
- 新展示文案走 sample 字符串资源；本轮不改变 Ncrust 业务、播放器三层架构或 Android 动效裁定。

## 验证

两仓 assembleDebug；模拟器覆盖普通手机、320×533dp、1280×800dp，深浅主题；
亲自读图检查按钮层级、长文本、sheet、歌词操作与系统栏。模拟器软件 GPU 不作为性能结论。
本仓没有测试套件，不新增空测试任务；调色板计算用独立数值脚本与截图颜色交叉核对。
